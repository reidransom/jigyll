# jigyll

Jekyll site for [jigyll.r2ware.app](https://jigyll.r2ware.app)

## Build

This is a jigyll website built and served with 
[`jigyll`](https://src.r2ware.dev/reid/jigyll), the Go implementation of Jekyll.

```sh
jigyll build     # build to _site/
jigyll serve     # build + watch + serve at http://127.0.0.1:4000
```

## Optional

Build and serve many sites with [servd](https://github.com/reidransom/servd).

Rev and sync static assets to CDN with [cdnware](https://github.com/reidransom/cdnware).
